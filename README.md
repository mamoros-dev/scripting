# BASH SCRIPTING

## Nuestro Roadmap de Aprendizaje (Bash & DevOps)

+ **Módulo 1:** Sintaxis Básica, Variables y Primeros Comandos (Donde estamos ahora: variables, sustitución de comandos, printf y limpieza de salidas).

+ **Módulo 2:** Redirecciones, Pipes y Manejo de Errores (stdout, stderr, /dev/null y cómo encadenar comandos para filtrar logs).

+ **Módulo 3:** Control de Flujo (Condicionales y Bucles) (if/else, validación de códigos de salida $?, bucles for para iterar sobre listas de servidores o archivos).

+ **Módulo 4:** Funciones, Argumentos y Robustez en Producción (Estructurar scripts limpios, uso obligado de set -euo pipefail para que el script falle de forma segura si algo va mal).

+ **Módulo 5:** Parsing de JSON y YAML con jq (Esencial para leer configuraciones de Kubernetes o salidas de la CLI de AWS).

+ **Módulo 6:** Aprenderemos a usar jq (el procesador de JSONs en terminal) y a combinarlo con comandos reales de AWS y Kubernetes para extraer información de infraestructura en segundos.
    
+ **Scripts:** Construiremos los scripts más demandados en entrevistas técnicas y operaciones reales de producción (health checkers, rotadores de logs, validadores de CI/CD, etc.).

+ **Píldora de Python + APIs REST:** Una guía práctica orientada al mundo real para consumir endpoints HTTP, parsear JSONs complejos y gestionar errores con código limpio, acompañada de un prompt experto para que puedas practicar por tu cuenta.

## 🌐 Las mejores webs interactivas para practicar Scripting

1. **SadServers (Imprescindible) https://sadservers.com/**
	• ¿Qué es?: Un "Capture The Flag" (CTF) de servidores Linux reales.
	• Por qué te sirve: Te dan una máquina virtual estropeada (ej. "el servidor web no responde" o "el disco se ha llenado y no sabemos por qué"). Te obliga a meterte por SSH y usar comandos de terminal o crear mini-scripts Bash para diagnosticar y solucionar el problema en producción.
2. **Exercism (Track de Bash) https://exercism.org/es-ES/tracks/bash**
	• ¿Qué es?: Plataforma 100% gratuita con retos lógicos.
	• Por qué te sirve: Te ayuda a dominar la sintaxis pura de Bash (bucles, condicionales, manipulación de cadenas de texto y expresiones regulares) mediante retos guiados que se evalúan automáticamente.
3. **Rebash (Python para DevOps) https://rebash.in/python/**
	• ¿Qué es?: Una hoja de ruta y tutorial enfocado exclusivamente en el Python que de verdad usa un DevOps (manejo de archivos JSON/YAML, automatización de Linux con subprocess y llamadas a la API de AWS con boto3).
